# IntrudeAware Final Report - LaTeX Package

This package contains the final CSE3010 Computer Vision project report for **IntrudeAware**.

## Compile

From this `report` directory:

```bash
latexmk -pdf IntrudeAware_Final_Report.tex
```

A standard `pdflatex` workflow can also be used by running it multiple times for references and the table of contents.

## Included evidence

- `figures/dashboard_settings.png` - sanitized final settings screenshot with project naming.
- `figures/dashboard_overlay.png` - supplied processed-video screenshot.
- `figures/event_dashboard.png` - supplied processing summary and event dashboard screenshot.
- `figures/event_metadata.png` - supplied event-log tail, metadata, and output-path screenshot.
- `evidence/IntrudeAware_events.csv` - supplied runtime event log.
- `figures/event_counts.png` - chart generated from the supplied runtime event log.
- `diagrams/` - editable/rendered architecture, workflow, use-case, and class/sequence artifacts.

The written report uses the term **project** throughout.
